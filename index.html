操作说明

把大哥云当作机场来用时，路径很短：对照套餐、取得订阅、下载客户端、导入并连接。按下列顺序做完，一般不必反复回到套餐页。

从订阅到连接

  1. 在套餐对照区确认流量习惯、同时在线设备，以及是否需要更完整的流媒体或游戏向线路。
  2. 完成订阅后，在账户侧复制机场订阅地址。只在本机或常用设备中保存，避免把链接发到公开聊天。
  3. 打开本页客户端下载区，按系统选择对应加速器客户端。以页面给出的入口为准，不另行寻找来路不明的安装包。
  4. 在客户端中选择「订阅 / 从 URL 导入」，粘贴地址并更新节点列表。
  5. 选一条可用线路连接。若失败，先检查系统时间、本地网络和订阅是否过期，再换线路或查看问答。

日常维护

流量接近上限时提前对照套餐，而不是等到中断。更换设备时重新导入同一订阅即可。长期不用可在客户端断开，以免后台消耗。

常见问题

大哥云是什么？和机场、VPN 加速器是什么关系？

大哥云是提供机场订阅与网络加速查阅的品牌站点。机场指可导入客户端的订阅服务，VPN 加速器则是承载连接的客户端形态。两者配合使用：订阅决定可用范围，客户端负责连接。

第一次使用要准备什么？

准备一台能安装客户端的设备、可用的本地网络，以及在套餐对照区选定的方案。完成订阅后复制链接，到客户端下载区安装软件，按「导入订阅 → 更新 → 连接」即可。

如何选择套餐，才不会选错档？

先估计每月流量和同时在线设备，再看是否需要更完整的流媒体或游戏向线路。把这些条件带到对照区逐项核对。不要只看月费，也不要在正文里寻找已经集中展示过的数值。

客户端下载后怎样导入机场订阅？

打开客户端的订阅或配置页，选择从 URL 导入，粘贴订阅地址并更新。成功后会出现线路列表。若列表为空，检查链接是否完整、账户是否仍在有效期，然后重试更新。

可以在哪些场景把大哥云当梯子用？

适合查阅、办公登录、影音和多设备出行备用。把大哥云当作稳定出口，而不是临时插件。场景明确后再连接，减少频繁切换造成的中断。

多台设备一起用要注意什么？

同一订阅可导入多台设备，但同时在线数量受所选套餐约束。超出后可能出现抢占或无法连接。给常用设备保留名额，临时设备用完即断开。

连不上时按什么顺序排查？

确认本地网络正常、系统时间准确、客户端为官网提供的版本、订阅已更新。仍失败则更换线路或系统代理模式。不要安装来路不明的「修复包」。
